# Form Shield — Roadmap

## ✅ v1.0 (shipped)
- Local auto-save with triple-redundancy storage
- Manual restore from popup
- Blacklist for sensitive sites & fields
- Floating shield badge

## ✅ v1.1 (this release)
- Auto restore-on-reload prompt banner
- Cross-tab sync (changes broadcast across tabs on same hostname)
- Google Drive sync (free tier)
- Supabase sync (Pro tier)
- Revamped popup UI with cloud sync controls

## 🔜 v1.2 — Polish (next 2-4 weeks)
- Show HN launch + Reddit campaigns
- 30-second demo GIF for README
- Landing page (formshield.dev) with email capture
- Browser compatibility: Firefox port
- Settings page for debounce delay, blacklist management
- Better Discord/Twitter cards (OG tags)

## 🔮 v2.0 — Expansion (3-6 months)
- **Team tier** — shared form templates for hiring, sales, support teams
- **Smart suggestions** — "you filled this on 14 sites, want a profile?"
- **Voice-to-form** — speak your answers instead of typing (Whisper API)
- **Form analytics** — see how long you spend on each form, where you abandon
- **Cross-browser** — Firefox + Safari (WebExtensions API)

## 💭 Future ideas (exploring)
- **Browser-agnostic cloud** so you're not locked to Chrome
- **Mobile companion** (read-only review of drafts you typed on desktop)
- **Enterprise** — admin console for companies that want this deployed to their fleet

## 📊 North star metric
**Weekly Active Restores** — number of times per week a user successfully recovers a saved draft.
This proves the product is solving the pain, not just sitting there.
